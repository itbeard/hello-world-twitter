## Running inside the VM

Install dependencies, load the read-only X credentials, and launch the web app:

    npm install && npm run dev -- --host 0.0.0.0 &
    # ready when http://localhost:3000/health responds 200

## Demo flow

Record one clear 30–40 second story. Use “I built my own publishing app.” for the introductory slide.

Open http://localhost:3000 and show the Junie Launchpad screen with the real X account, avatar, and prefilled “Hello World” text. Click “Publish to X” exactly once, keep the API wait and the transition from the button to “Hello, X.” at normal speed, then wait until “Published” and “View post” appear. Open “View post” and show the real post on X. Do not expand the recording panel and do not publish the video reply during this recording.

Use “Built by Junie. Published by Junie. Recorded with /demo.” for the final slide.
